Bean Counter wireframes

Low-fidelity wireframes of the screens in docs/plan.md. They are for design only and are never reused as app code. Each flow file has a desktop layout (1440 px wide) and a mobile layout (390 px wide). Use the dark bar at the top of a flow to switch screens and devices, or click the buttons inside the wireframe to walk through the flow.
